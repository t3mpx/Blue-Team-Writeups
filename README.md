# Blue-Team-Writeups
Writeups of blue team scenarios I have investigated to practise and improve my skills in incident investigation, log analysis and threat detection. I work as a CSIRT analyst and use this repository to document my method: what I looked at, which tools and queries I used, what I found, and what I would recommend.

Each writeup follows the same structure: scenario, investigation steps with evidence (commands, queries, screenshots), indicators of compromise where relevant, remediation, and conclusion.
